### 🛠️ What I Build

<p align="center">
  <a href="https://github.com/Sonophage/Bureau">
    <img width="75%" src="https://raw.githubusercontent.com/Sonophage/Bureau/main/screenshots/bureau-hero.webp" alt="Bureau — a noir theme for Obsidian" />

- **[Bureau](https://github.com/Sonophage/Bureau)** — a noir theme for Obsidian. A worn case-file on a concrete desk; one accent colour drives the whole UI (Control red, Magnus green, Deus gold).
- **[Redacted Background](https://github.com/Sonophage/Redacted-Background)** — companion plugin for Bureau: point-and-click local wallpapers and new-tab images, no base64, no hand-editing.
- **[Rhizone Graph](https://github.com/Sonophage/Rhizone-Graph)** — an Obsidian plugin: a per-note connection-web of direct links, curated connections, and rarity-ranked co-citation candidates.
